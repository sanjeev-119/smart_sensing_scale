# Smart Sensing Scale — team site

Starter site for the project, styled around a "clinical readout" theme
(temperature/pressure sensor data) rather than a generic template look.

## What to edit

- `index.html` — every `[bracketed placeholder]` is something to replace:
  team member names/roles/bios, advisor names, spec values, and report/document
  filenames.
- `assets/team/` — drop in headshots named `member-1.jpg`, `member-2.jpg`, etc.
  (or update the `src` paths in `index.html` to match your filenames).
- `assets/reports/` — drop in your weekly report PDFs.
- `assets/documents/` — drop in your design docs, poster, and slides.

Tip: avoid spaces in filenames (use hyphens/underscores) so links don't break.

## Preview locally

Open the folder in VS Code, right-click `index.html`, and choose
**"Open with Live Server."**
